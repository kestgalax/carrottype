# CarrotType 0.11.0

2026-11-12

Настройки собраны по сценариям: «Основные», «Диктовка» и «Преобразования».

## Новое

- «Основные» — только о приложении. Обновления, версия и «Что нового», тема, язык интерфейса и запуск при входе в macOS теперь находятся в «Основных» и больше не смешиваются с настройками диктовки.
- У «Диктовки» свои настройки. Сочетание клавиш диктовки, режим рации, сохранение результата в буфере, режим и правила оформления, «Мои правила» и пробный текст собраны в «Диктовке». Оформление по-прежнему доступно только в состоянии Ready.
- «Преобразования» — для связок. Связки Translate и Custom вместе с выбором модели, языка и инструкции переехали в «Преобразования». Ограничения и проверка конфликтов не изменились.

## Улучшено

- Восемь разделов в понятном порядке. В боковом списке теперь: «Основные», «Диктовка», «Преобразования», Dynamic Island, «Настройка», «Модели», «Хранилище» и «Статистика». Название раздела Dynamic Island по-прежнему не переводится.
- Сохранённое не сбрасывается. Размер окна, минимум 720×520, стартовый раздел по состоянию Ready, все сохранённые значения и связки остаются прежними. Прокручивается только список разделов; Details, версия и «Что нового» остаются на месте.
- Уход из раздела ничего не ломает. При уходе из «Диктовки» или «Преобразований» захват сочетания отменяется, а горячая клавиша снова регистрируется. Уход из «Диктовки» также отменяет идущую пробу текста; смена языка или темы не пересоздаёт настройки и не останавливает завершённую пробу.

## Установка

Обновитесь через «Проверить обновления» в CarrotType или скачайте DMG и перенесите приложение в «Программы». Модели, настройки, статистика и выбранный режим Dynamic Island сохраняются. Название раздела **Dynamic Island** по-прежнему не переводится. GigaAM в этот выпуск не входит.

Сборка подписана CarrotType Development, но не Developer ID и не нотаризована. При первом скачивании macOS может потребовать: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
