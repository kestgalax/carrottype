# CarrotType 0.3.10 (23) — Debug для ручной проверки

Статус: Debug-кандидат проверен пользователем; все пункты подтверждены сообщением «по всем — ок». Release DMG готовится к публикации. Ветка: `fix/dictation-reliability`.

## Запуск

Приложение: `dist/CarrotType-0.3.10-Debug/CarrotType.app` (от корня репозитория).

1. Завершить текущий CarrotType через его меню, чтобы два экземпляра не конкурировали за горячие клавиши.
2. Открыть этот Debug `.app` напрямую. Установленное `/Applications/CarrotType.app` не заменено.
3. В подробностях настроек проверить версию `0.3.10`. При необходимости разрешить микрофон/Accessibility именно для запускаемого Debug-приложения; после смены подписи или пути macOS может потребовать повторной выдачи прав.
4. Модели, настройки и статистика используются из существующего профиля. Debug использует тот же bundle ID и данные; изменения настроек в нём сохранятся и для установленной версии. Новые модели не скачиваются автоматически.
5. Чтобы вернуться к опубликованной версии, завершить Debug и открыть `/Applications/CarrotType.app`.

Подписано существующим локальным сертификатом CarrotType Development. Это не Developer ID и не notarized release.

## Что изменилось

- Отложенное восстановление буфера не затирает более новую копию. Восстанавливаются пустое состояние, несколько элементов и rich types.
- Меню → «Скопировать последнюю диктовку» и «Забыть последнюю диктовку». Один завершённый текст хранится только в RAM; отмена/сбой следующей записи его не стирают. Очистка и выход удаляют этот recovery state.
- Известная ошибка вставки показывает текст с Copy/Close в Capsule. «Готово» означает отправленную команду вставки, а не подтверждение от приложения-получателя.
- Подробности доступны при Ready; последняя ошибка остаётся видимой после обновления разрешений. Её можно скрыть, успешная следующая диктовка/transform также её сбрасывает.
- Helper читает оба pipe во время работы, ограничивает вывод и завершается при timeout/cancel. Ранний выход helper не должен закрывать CarrotType через SIGPIPE.
- Выбор моделей и все существующие функции сохранены; переход на Ultra будет отдельной версией после этого этапа.

## Чеклист пользователя

- [x] Обычная RU/EN диктовка вставляется в редактор и поле браузера; Capsule заканчивает «Готово».
- [x] После диктовки Copy Last Dictation возвращает тот же текст. Отменить следующую запись через Escape — предыдущий текст всё ещё доступен. Clear Last Dictation убирает его.
- [x] С выключенным retain clipboard прежнее содержимое возвращается. С включённым — результат остаётся для ⌘V. Новая копия, сделанная сразу после вставки, не исчезает.
- [x] Toggle и hold-to-talk, live draft, Escape → Copy preview работают как прежде. На молчании нет неожиданной вставки.
- [x] Smart/Gemma и Translate/Custom дают результат. Ошибка transform (например, нет выделения) видна в меню и Details при Ready, переживает Refresh и исчезает после успешной операции/явного скрытия.
- [x] В Settings работают смена RU/EN, входной микрофон/meter, Wave Link unmute/restore (если используется), модели/Storage и opt-in статистика. Проверить соответствующие используемые функции, не удаляя модели ради теста.

При обнаруженной ошибке сообщить сценарий, выбранную модель/форматирование и ожидаемый/фактический результат. Записи голоса и личные тексты для отчёта не нужны.

## Известные ограничения

- CGEvent не подтверждает реальную вставку. Если целевое приложение проигнорировало ⌘V, восстановить текст через меню Copy Last Dictation.
- У macOS clipboard нет надёжного идентификатора автора записи: внешняя копия одновременно с fallback ⌘C может быть принята за запрошенное выделение. AX-selected-text путь не использует этот fallback.
- Загрузка сетевых моделей, updater, модельные defaults и lifecycle-рефакторинг этой версией не меняются; известные residual risks из security docs сохраняются.

**Gate ручной проверки для 0.3.10 пройден: пользователь подтвердил все пункты. После этого исходный код приложения не менялся. Следующие версии требуют собственной Debug-сборки и отдельного подтверждения.**
