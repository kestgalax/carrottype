# CarrotType 0.8.0

2026-11-10

Постобработка по вашим правилам и выбор темы\.

## Новое

- Правила постобработки\. Удаление слов, строчные буквы и последняя точка настраиваются без модели и работают при её отказе\. Пожелания модели и экспериментальный деловой стиль можно проверить на тексте\.
- Системная, светлая или тёмная тема\. Выбор независим от языка, применяется сразу и сохраняется после перезапуска\.

## Улучшено

- Две предлагаемые модели\. Qwen3 0\.6B и Gemma; установленный Smart\+ сохраняется для совместимости с существующими настройками и действиями\.

## Исправлено

- Бережная базовая обработка\. Сохраняет смысловые слова и переносы строк\.
- Защита от обрезанного результата модели\. Учёт токенов защищает от обрезанного ответа; обнаруженная потеря защищённых значений тоже вызывает видимый переход на базовую обработку\.

## Установка

Обновитесь через «Проверить обновления» в CarrotType или скачайте DMG и перенесите приложение в «Программы». Модели, настройки и статистика сохраняются.

Сборка подписана CarrotType Development, но не Developer ID и не нотаризована. При первом скачивании macOS может потребовать: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## Ограничения

Деловой стиль экспериментальный и по умолчанию выключен: Gemma может не изменить стиль или вернуть отклонённый результат. Точные настройки продолжают работать при отказе модели.

## Проверка выпуска

Принятый Debug, чистая Release arm64, подписи приложения/обновления, DMG и изолированная установка A29→B30 проверены. Локальный Release helper проверен на установленной Gemma. Исходники: `v0.8.0` / `819286a`, PR #27. [GitHub CI](https://github.com/kestgalax/carrottype/actions/runs/42891053801) прошёл: регрессии, Debug arm64 и проверки настоящего AppState. Подписи и контрольные суммы скачанных файлов черновика и публичного релиза совпали с локальными. Публичный канал обновлений проверен без авторизации; изолированный Sparkle обнаружил новую версию с build 29 без установки. Независимая полная проверка TCC, устройств, VoiceOver и сети не заявляется; Qwen не оценивался.
