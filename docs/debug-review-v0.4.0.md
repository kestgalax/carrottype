# CarrotType 0.4.0 (24) — Debug для ручной проверки

Статус: Debug проверен пользователем 2026-11-10; подтверждены все пункты, получено явное разрешение на публикацию. Release DMG готовится. Ветка: `feat/ultra-only-dictation` от main после выпуска 0.3.10. Подтверждение 0.3.10 не заменяет эту проверку.

## Запуск

Закрыть текущий CarrotType через Выход и открыть `dist/CarrotType-0.4.0-Debug/CarrotType.app`. Проверить версию **0.4.0** в настройках. Два экземпляра одновременно запускать не нужно: они конкурируют за hotkey.

Установленное `/Applications/CarrotType.app` не заменено. Debug использует общий профиль моделей/настроек/статистики. При запуске сохранённый STT id меняется на Ultra; остальные настройки сохраняются. macOS может потребовать Accessibility/микрофон для другого пути приложения. Подпись локальная CarrotType Development, без notarization.

## Что проверить — около пяти минут

1. **Модели:** в диктовке только Parakeet Ultra, без переключателя и без предложений скачать Whisper/v3/Apple. Если Ultra уже установлена, сразу Ready без повторного скачивания. Форматирование Off/Light/Smart/Smart+/Gemma осталось.
2. **Речь:** продиктовать русскую и английскую фразы, затем фразу с числами и смесью языков, например «Завтра в пятнадцать тридцать обсудим release notes для CarrotType». Текст должен вставляться как прежде; проверить обычный режим и удержание, живой текст и Escape.
3. **Storage:** прежние модели видны отдельно. Нажать Delete на ненужной старой модели и сначала **Отмена** — ничего не удаляется. Реальное удаление необязательно: если выберешь его, исчезнуть должны только файлы выбранной старой модели. Ultra/cleanup остаются. Для Apple удаляется лишь локальная отметка, системные пакеты остаются.
4. **Остальные функции:** перевод выделения/Custom, выбранное форматирование, Copy Last Dictation, RU/EN интерфейс и используемый микрофон/Wave Link работают как раньше. Статистика и настройки не сброшены.

Если Ultra отсутствует, UI должен предложить явное скачивание; оно не начинается само. Ради этой проверки не требуется удалять установленную Ultra. Автоматические проверки миграции/очистки уже выполнены на временных данных, а не на твоих моделях.

Чтобы вернуться к 0.3.10, закрыть Debug и запустить прежнюю копию приложения. Сохранив старые веса, можно снова выбрать прежнюю модель в 0.3.10; после их добровольного удаления потребуется повторное скачивание.
