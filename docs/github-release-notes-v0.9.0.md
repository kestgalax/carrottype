# CarrotType 0.9.0

2026-11-11

Три способа показывать статус диктовки и более спокойный Dynamic Island\.

## Новое

- Настройки Dynamic Island\. Полная капсула \(по умолчанию\), минимальная индикация или только строка меню — в отдельном разделе Dynamic Island сразу после Основных\. Название раздела не переводится\.
- Минимальная индикация\. Тонкая красная подсветка записи под вырезом и три точки обработки — или компактный индикатор сверху по центру на экранах без выреза\. Без текстового тела; учитываются «Уменьшение движения» и «Повышение контраста»\.
- Только строка меню\. Статус диктовки не показывается отдельной панелью, остаётся прежняя иконка в строке меню\. Результаты перевода и восстановление после ошибки вставки по\-прежнему показываются с «Копировать»/«Закрыть»\.

## Улучшено

- Сохранённый выбор живого текста\. Переключатель «Показывать текст, пока говорите» переехал в Dynamic Island со своим прежним значением\. Он доступен только в полной капсуле и возвращается без сброса\.
- Изменения — со следующей диктовки\. Режим фиксируется при старте диктовки, поэтому его смена не прерывает текущую запись или обработку текста\.
- Предупреждение об оформлении\. Если статусная панель скрыта, предупреждение о базовой обработке остаётся в меню и подробностях\.

## Установка

Обновитесь через «Проверить обновления» в CarrotType или скачайте DMG и перенесите приложение в «Программы». Модели, настройки, статистика и выбранный режим Dynamic Island сохраняются. Это функциональный выпуск Dynamic Island; GigaAM в него не входит и остаётся отложенным.

Сборка подписана CarrotType Development, но не Developer ID и не нотаризована. При первом скачивании macOS может потребовать: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## История изменений

Опубликованные заметки 0.8.2 перенесены в неизменяемую `ReleaseNotesHistory.json` без изменения прежней записи. Полная структурированная история начинается с 0.6.1; «Что нового» и подписанный inline-фид показывают пропущенные версии офлайн. Неполная история обозначается явно.
