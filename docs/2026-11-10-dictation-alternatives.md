# Альтернатива Parakeet Ultra: отдельный этап 0.9.0

Дата проверки: 2026-11-10. Статус: исследование первичных источников и план, **без скачивания весов, запуска моделей, изменения приложения или выбора победителя**. Пользователь попросил рассмотреть дополнительный выбор диктовки отдельной версией, после 0.8.0 (постобработка/правила/тема). Версия 0.9.0 целевая; перед реализацией сверить актуальные релизы. Новая ветка `plan/stt-alternative-0.9` создана от main `6bc31ec`; предыдущие planning-коммиты 0.8.0 перенесены с сохранением содержания.

## Рекомендация

Первым сравнить **Parakeet Ultra ↔ Qwen3-ASR 0.6B ↔ Qwen3-ASR 1.7B**, Whisper large-v3-turbo использовать как контроль. Если дополнительная модель даёт ощутимую пользу на русской/английской диктовке и приемлемое ожидание, предложить **Ultra + один выбранный альтернативный пакет**, не возвращать каталог из множества похожих вариантов. Ultra пока остаётся текущим/default/recommended; отказ от единственной предлагаемой STT из ADR-016 — новый ADR до реализации. Не обещать, что Qwen распознаёт лучше Ultra на пользовательском Mac: такого теста ещё нет.

**Qwen3-ASR — модель аудио→текст.** Это не Qwen3 0.6B для форматирования и не снимаемый Smart+ 1.7B. Размер в параметрах не означает одинаковый пакет/задачу/скорость; ASR и cleanup имеют отдельные id, скачивания, память и UI.

## Кандидаты и практический смысл

| Кандидат | Что подтверждено | Практический интерес / ограничения | Приоритет |
|---|---|---|---|
| **Qwen3-ASR 0.6B / 1.7B** | Автор заявляет 30 языков + 22 китайских диалекта, включая RU/EN, offline/streaming; открытые веса. MLX-конверсии и Swift ASR реализация существуют. | Иная архитектура как реальная альтернатива Ultra; проверить термины, смешанный RU/EN, имена, числа. 0.6B — более компактный из двух, 1.7B — кандидат для сравнения качества, без обещания победы. Новый ASR-адаптер/зависимость, отдельная проверка GPU/RAM/lifecycle. | **Основной A/B** |
| **Whisper large-v3-turbo** | Открытая мультиязычная модель; есть Swift/Core ML путь WhisperKit/argmax-oss-swift. | Полезный контроль другой модели. В CarrotType раньше был Whisper, но адаптер/прямая зависимость удалены ADR-016; это не «просто включить скрытый пункт». Сравнить silence/hallucinations, short takes и cold start. | Контроль, возможный резерв |
| **GigaAM v3 E2E / Multilingual** | Официальный репозиторий: v3 ориентирован на русский, E2E включает пунктуацию/нормализацию; отдельная Multilingual-линейка 220M/600M покрывает 70+ языков, с оговоркой о более умеренном английском. | RU-специализация интересна; не считать всю семью русскоязычной. Нативная Swift/MLX-конверсия, longform, VAD и RU/EN switching требуют отдельной проверки. Официальный Python longform-пример требует gated pyannote/token — не переносить этот путь в продукт с анонимной установкой. | Второй круг для RU |
| **Parakeet Redux** | Core ML пакет ~220 MB, 25 языков, macOS 15+. В нашем разрешённом FluidAudio 0.17.7 enum `.redux` уже есть. | Интересен меньшей загрузкой, не установленным преимуществом качества. Вендорская проверка показывает проигрыш v3 на русском; это не наш тест и не сравнение с Ultra. Первый ANE compile может быть долгим; проверить cold/warm и наш macOS 14 floor. | Только если нужен компактный вариант |
| **Voxtral Mini 4B Realtime** | Открытая Mistral streaming-модель; есть русский в таблице автора и community C/Metal путь для Apple Silicon. | В первую очередь исследовать настоящий streaming, если он станет отдельной целью. Более тяжёлый кандидат/другой runtime; цифры 480ms из model card — настройки/результаты автора, не задержка нашего приложения на Mac. | Резерв, не первый дополнительный выбор |
| **Qwen-Audio-3.1-ASR** | Есть свежий отчёт и project page с демо; проверенная страница не даёт нам подтверждённого локального Swift-compatible open-weight checkpoint. | Не путать новую презентацию/API семейства с уже доступным локальным Qwen3-ASR 0.6/1.7B. Повторить проверку открытых весов перед этапом. | Наблюдать |

Parakeet v3 как ещё один похожий пакет и English-only модели не возвращать без отдельной причины. Облачные ASR/API не входят в этот этап: аудио остаётся на устройстве, доступность интернета после установки не условие диктовки.

## Что потребуется в нашем коде

- Сейчас ParakeetSTTEngine/StreamingParakeetSTTEngine и ModelManager ориентированы на Ultra, не на универсальный catalog switch. Проверить весь путь: package ready/download/delete, storage/cache, selected model, Setup readiness/trial, session snapshot, final WAV, language auto, live draft, unload/cancel/quit и install gate. В опубликованном Package.resolved FluidAudio 0.17.7 / `503b4bd…`; возможности latest README не автоматически возможности выбранного пина.
- Наличие MLX у cleanup helper не обеспечивает поддержку Qwen ASR: аудиопроцессор/encoder/ASR decoder и отдельный STTEngine нужны самостоятельно. Предпочтительна изоляция MLX ASR из host с явным cancellation/unload; решение процесса/зависимости/пинов — предмет ADR и spike, не уже выбранная архитектура. Пакет Swift должен работать без Python/Homebrew и без скрытых моделей/загрузок в диктовке.
- Swift `generateStream(audio:)` в README означает выдачу результатов генерации; само по себе не доказывает настоящий инкрементальный вход микрофонного PCM или совместимость с нашим live draft. Проверить поддержку отдельно. Не отключать preview незаметно; сохранность существующего Ultra preview обязательна. Если альтернатива требует ограничений, показать и согласовать их до включения в release.
- MLX ASR на GPU и последующее Gemma/Qwen cleanup могут давать пик памяти. Замерять последовательный полный путь с освобождением ASR до следующей модели, включая отмену/ошибку, без параллельной гонки unload и следующего сеанса.
- Новая выбранная модель только из уже Ready пакетов; скачивание/удаление явные, не менять Ultra default, не скрыто запускать другую STT при сбое, не удалять старые веса. При неудаче новой STT — понятная ошибка/явный выбор Ultra, а не ложный успешный результат. UI двух моделей с понятными названиями, размером и фактическими ограничениями.

## Этапы отдельной версии 0.9.0

**S1 — эксперимент без изменения shipping runtime.** Проверить нативные SDK, лицензии, конкретные revision/размер/контекст/streaming, совместимость с macOS 14 и пинами MLX/SPM. До написания экспериментального адаптера с новой runtime-зависимостью оформить отдельный ADR исследовательского spike с ограниченной областью; production-выбор остаётся отдельным решением S3. Подготовить воспроизводимый benchmark harness в изолированной research-папке; никакого незаявленного изменения реальных настроек/моделей. Авторские/серверные WER/скорость — контекст, не результат CarrotType. Публичные совместимые с лицензией записи либо явно предоставленные для теста; не забирать историю/микрофон пользователя автоматически.

**S2 — сравнительный прогон и решение.** Одни и те же WAV для Ultra, Qwen ASR 0.6/1.7 и контрольного Turbo. Сначала cleanup Off, чтобы LLM не маскировала ошибки STT; затем один и тот же фиксированный cleanup как дополнительная end-to-end проверка. Набор: 30–50 коротких RU/EN/mixed фраз и несколько длинных takes, разговорная/быстрая речь, имена/названия/числа/отрицания/термины, тишина/шум, исправления. Часть корпуса отложить для подтверждения, не подгонять настройки на всём наборе. Метрики: нормализованный и исходный WER/CER, сохранение критичных сущностей, галлюцинации на тишине, p50/p95 stop→итог, cold start/first use compile, peak RAM, idle RAM после unload, live draft/отмена. Зафиксировать Mac/OS/compute units/quantization/версии и стоимость сравнительных запусков по времени/энергии. Не переносить серверную throughput в ожидания для ноутбука.

**Decision gate:** выбрать не более одной альтернативы, только если продемонстрирована понятная польза хотя бы в заранее выбранном сценарии без неприемлемой задержки/памяти или регрессии базового цикла. Если выигрыша нет — публикуется исследование, новый пункт не добавляется ради галочки. Результаты и компромисс обсудить с пользователем до production-интеграции; исследовательский этап разрешён этим запросом, конкретная STT/зависимость пока не выбраны.

**S3 — интеграция после решения.** Новый Accepted ADR, уточняющий/частично superseding ADR-016 и описывающий новый engine, host/helper boundary, model pin/licensing/download/storage, cancellation/live preview policy. Новая ветка от актуального main после 0.8.0. STTEngine + catalog/runtime selector + setup/General/Models/Storage + RU/EN, тесты maintenance/capture/streaming/session/updater boundary. Не смешивать с выбором cleanup-моделей или правилами постобработки. Документы: product intent, architecture, UX, roadmap, quality-note/eval, ADR и release notes.

**S4 — Debug и выпуск.** Signed Debug 0.9.0, 2–3 ручных сценария на выбранных RU/EN/mixed фразах, сохранности live draft/отмены и explicit switch/Ready состояния. После принятия — отдельное разрешение на публикацию, clean Release/DMG и подписи local/draft/public updates. Приложение по-прежнему без bundled weights. После проверки архивировать лишние .app, чтобы не засорять Spotlight.
