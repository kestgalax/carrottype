# CarrotType 0.8.2

2026-11-11

Что нового за все пропущенные версии\.

## Улучшено

- Все пропущенные изменения\. Окно обновления и «Что нового» показывают изменения между прежней и новой версией, сгруппированные по релизам\. История после установки доступна без интернета\.

## Установка

Обновитесь через «Проверить обновления» в CarrotType или скачайте DMG и перенесите приложение в «Программы». Модели, настройки и статистика сохраняются.

Сборка подписана CarrotType Development, но не Developer ID и не нотаризована. При первом скачивании macOS может потребовать: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## История изменений

В окне обновления показываются пропущенные релизы; после установки они доступны офлайн в «Что нового». Структурированная история начинается с 0.6.1. Если прежняя версия не была записана приложением, офлайн-окно показывает текущий релиз; неполная история обозначается явно, полный список доступен по ссылке.

## Проверка выпуска

Подписанный Debug принят для публикации. Локальные проверки диапазонов/перезапуска/повреждённой истории, реального AppState и подписи Debug прошли. Проверена фильтрация в настоящем компоненте Sparkle с отключённым JavaScript содержимого, а также нативное окно на русском/английском в светлой/тёмной теме. Изолированная установка A31→B32 и отрицательные сценарии прошли; это не независимая проверка старого бинарного файла или TCC. Полная интерактивная проверка устройств, VoiceOver и сети не заявляется.

Чистая Release arm64, подписи приложения/компонентов, смонтированный DMG, полный архив истории и подписанный ZIP/appcast проверены. [CI исходников приложения](https://github.com/kestgalax/carrottype/actions/runs/42995404697) прошёл для `4f85180`; локальный governance прошёл, приватный hosted AIDOS явно пропущен. Тег `v0.8.2`, PR #29. Подписи и контрольные суммы скачанных файлов черновика и публичного релиза совпали с локальными. Публичный канал обновлений проверен без авторизации; изолированный Sparkle обнаружил обновление с build 31 без установки. Исходники тега: `62082f6`.
