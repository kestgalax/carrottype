# CarrotType 0.8.1

2026-11-11

CarrotType под рукой после включения Mac\.

## Новое

- Запуск при входе в macOS\. Включите автозапуск в Основных\. После перезагрузки или включения Mac приложение появится в строке меню при входе в систему\. Необходимость разрешения macOS и ошибки показываются явно\.

## Установка

Обновитесь через «Проверить обновления» в CarrotType или скачайте DMG и перенесите приложение в «Программы». Автозапуск включается отдельно: **Основные → самый низ → «Запускать при входе в macOS»**. Модели, настройки и статистика сохраняются. При необходимости подтвердите запуск в настройках объектов входа macOS.

Сборка подписана CarrotType Development, но не Developer ID и не нотаризована. При первом скачивании macOS может потребовать: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## Проверка выпуска

Принят обновлённый подписанный Debug. Проверки политики автозапуска используют подставной системный адаптер и не меняют реальные объекты входа. Изолированная установка A30→B31 и проверки недоступного канала, изменённой подписи и повреждённого архива прошли. Индивидуальные результаты ручной перезагрузки и разрешения macOS не перечислялись. Независимая полная проверка TCC, устройств, VoiceOver и сети не заявляется.

Чистая Release arm64, подписи компонентов, смонтированный DMG, совпадение архива с приложением, локальные подписи ZIP/appcast и проверки governance прошли. [GitHub CI](https://github.com/kestgalax/carrottype/actions/runs/42983616038) прошёл для кода приложения `fe2e9bc`; локальный governance прошёл, приватный hosted AIDOS явно пропущен. Релиз: `v0.8.1`, PR #28. Подписи и контрольные суммы скачанных файлов черновика и публичного релиза совпали с локальными. Публичный канал обновлений проверен без авторизации; изолированный Sparkle обнаружил новую версию с build 30 без установки. Исходники тега: `d8e166b`.
