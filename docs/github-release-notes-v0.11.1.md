# CarrotType 0.11.1

2026-11-12

Заметки обновления и стандартное окно обновления теперь следуют выбранному языку, переключатель фоновой загрузки объясняет свою зависимость, а выход во время диктовки больше не отменяет установку.

## Исправлено

- **«Что нового» и окно обновления говорят на одном языке.** Русские и английские заметки теперь выбираются по одному общему правилу, поэтому «Что нового» сразу совпадает с интерфейсом. Стандартное окно Sparkle подхватывает выбранный язык при следующем запуске: macOS кэширует предпочитаемые языки приложения при старте процесса. Выбор «Системный» удаляет только переопределение, записанное CarrotType, и не трогает ваш собственный выбор языка для приложения.
- **Переключатель загрузки объясняет зависимость.** Sparkle разрешает фоновую загрузку только при включённых автоматических проверках. Пока проверки выключены, как по умолчанию, переключатель остаётся неактивным и теперь объясняет причину, а не выглядит сломанным. Ручная проверка обновлений и установка при выходе по-прежнему доступны.
- **Выход во время диктовки не блокирует установку.** Если обновление уже скачано и выбрана установка при выходе, приложение сначала завершает текущую диктовку, преобразование или оформление текста, а не отменяет выход, и затем передаёт установку Sparkle. Принудительной перезагрузки нет: установка идёт по документированному пути Sparkle после закрытия приложения.

## Установка

Обновитесь через «Проверить обновления» в CarrotType или скачайте DMG и перенесите приложение в «Программы». Модели, настройки, статистика, разрешения и выбранный режим Dynamic Island сохраняются. Обновление, уже скачанное до выхода из приложения, устанавливается после завершения текущей диктовки или преобразования; принудительного перезапуска нет.

Сборка подписана CarrotType Development, но не Developer ID и не нотаризована. При первом скачивании macOS может потребовать: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## История изменений

Опубликованные заметки 0.11.0 перенесены в неизменяемую `ReleaseNotesHistory.json` без изменения прежней записи. Полная структурированная история начинается с 0.6.1 и теперь непрерывна от сборки 35 до 27; «Что нового» и подписанный inline-фид показывают пропущенные версии офлайн. Неполная история обозначается явно.

## Проверка выпуска

Maintainer поручил проверить исправление языка заметок и установки при выходе и, если оно в порядке, опубликовать. Debug принят координатором на ветке `kestgalax/update-locale-quit-fix-2` (код `f0cff02`, evidence `7633120`). Опубликованная стабильная сборка уже 0.11.0 (35), поэтому текущий выпуск — **0.11.1 (36)**. Исходный код приложения заморожен на `f0cff02`; релизная работа меняет только версию/сборку, `ReleaseNotes.json`/`ReleaseNotesHistory.json`, project metadata и документацию.

Локальные проверки: `verify-release-notes.sh` (непрерывная история 36→27, RU/EN и языковой мост) и `verify-app-updates.sh` (очередь/занятость/gate, дренаж при выходе, единственный маршрут завершения) — PASS. Чистая arm64 Release-сборка; Finder layout вернул `-1743`, поэтому использован checksum-verified DMG-шаблон 0.11.0 с сохранёнными `.DS_Store`, background, layout и Applications-ссылкой. Финальный DMG прошёл `hdiutil verify`, mounted app/helper/MLX/identity проверены, весов моделей нет. ZIP/appcast подписаны и проверены; RU/EN описания содержат текущий релиз и девять исторических записей. Изолированная нативная установка A35→B36 и негативные сценарии (offline/tampered feed/corrupt archive/no-new-version) прошли на свежей staging identity; это candidate-code fixture, не исторический бинарник и не TCC.
