# CarrotType

<img src="macos/Brand/CarrotType-Mark.svg" width="48" height="48" alt="CarrotType">

Говорите — текст появляется у курсора. На Mac, локально, без облака.

CarrotType живёт в строке меню: одно сочетание клавиш записывает речь, распознаёт её на устройстве и вставляет результат в любое приложение, где вы сейчас печатаете.

## Зачем

- **Быстрее набора** — диктовка вместо долгой печати.
- **Приватно** — аудио не уходит на чужие серверы; модели работают на вашем Mac.
- **Везде, где есть курсор** — почта, чаты, документы, браузер.
- **Преобразование выделения** — отдельная горячая клавиша переводит или переписывает уже выделенный текст (локально); результат в Capsule.
- **Статус без лишнего шума** — в **Настройки → Dynamic Island** можно оставить полную капсулу, включить минимальную индикацию записи/обработки или показывать статус только в строке меню. Результаты перевода и восстановление текста остаются доступны в любом режиме.
- **Русский и английский** — интерфейс и распознавание под оба языка.
- **Parakeet Ultra для диктовки** — одна локальная модель без лишнего выбора; форматирование текста можно настроить отдельно.
- **Микрофон можно держать выключенным** — экспериментально для **Elgato Wave Link**: горячая клавиша сама снимает mute на время диктовки и возвращает его после, без отдельного физического включения/выключения микрофона.

## Требования

- Apple Silicon Mac
- macOS 14 или новее

## Установка

1. Скачайте `.dmg` из [Releases](https://github.com/kestgalax/carrottype/releases) и перетащите **CarrotType** в **Программы**.
2. Сборка **не нотаризована**. При первом запуске macOS обычно **блокирует** приложение (недостаточно просто дважды нажать «Открыть»):
   1. В Finder → **Программы** откройте CarrotType (или **ПКМ → Открыть**).
   2. В диалоге подтвердите, что понимаете предупреждение / закройте его, если система только сообщает о блокировке.
   3. Откройте **Системные настройки → Конфиденциальность и безопасность** (Privacy & Security) и в блоке про заблокированные приложения нажмите **Все равно открыть** / **Open Anyway**.
   4. Ещё раз подтвердите открытие CarrotType в появившемся запросе.
3. Разрешите **Микрофон** и **Универсальный доступ**.
4. В настройках скачайте Parakeet Ultra. Если модель уже установлена, приложение использует её без повторного скачивания. Раздел Setup проведёт по шагам и предложит пробную диктовку прямо внутри настроек.
5. Поставьте курсор в поле ввода, нажмите горячую клавишу (по умолчанию **⌥/**), говорите, нажмите ещё раз — текст появится на месте. В **Настройки → General** можно включить **режим рации**: только удержание — отпустили, распознать и вставить (повторное нажатие не останавливает запись).

Опционально: в **Настройки → Основные** включите **«Запускать при входе в macOS»**. CarrotType появится в строке меню после входа в систему, в том числе после перезагрузки или включения Mac. Для автозапуска приложение должно быть открыто из «Программ»; запись начинается только по вашему действию.

Опционально (Elgato Wave + Wave Link): в **Настройки → Setup** включите **Unmute mic during dictation (experimental)**. Wave Link должен быть запущен; по умолчанию опция выключена.

## Обновления приложения

Проверяйте обновления прямо из меню или настроек. Автоматическую проверку и скачивание можно включить отдельно; подписанное обновление дождётся завершения диктовки или обработки текста. Модели и настройки сохраняются на Mac. Кнопка «Что нового» в General и Details показывает изменения всех пропущенных версий после обновления, сгруппированные по релизам, даже без интернета. Первую версию с updater (0.5.0) установите вручную из DMG. [Подробнее об обновлениях и выпуске](ops/deploy.md#signed-application-updates--050-adr-017).
